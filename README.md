# Marketplace Freelance

پلتفرم فریلنسری برای اتصال کارفرمایان و فریلنسرها؛ کارفرما پروژه ثبت می‌کند، فریلنسرها پیشنهاد می‌دهند و کارفرما بهترین پیشنهاد را انتخاب می‌کند.

## هدف پروژه
پیاده‌سازی یک وب‌اپلیکیشن مشابه Ponisha / Upwork در قالب پروژه درس آزمایشگاه نرم‌افزار.

## نقش‌های اصلی
- **کارفرما (Client):** ثبت پروژه، بررسی پیشنهادها، انتخاب فریلنسر
- **فریلنسر (Freelancer):** تکمیل پروفایل و نمونه‌کار، جست‌وجوی پروژه، ارسال پیشنهاد
- **مدیر (Admin):** مدیریت کاربران و پروژه‌ها

## پایگاه داده
PostgreSQL 17 (دیتابیس آزمایشی: `lab_freelance`)
